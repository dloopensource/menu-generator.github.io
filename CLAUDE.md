## Tools Agents MUST use when working on this project

## Specifications written in Allium

* Specifications must be written using Allium
* See documentation for more information: https://github.com/juxt/allium

### Tasks on GitHub Project

GitHub Project board: https://github.com/users/dloopensource/projects/2/views/1

* Before implementing any changes, all tasks must be created on the GitHub project board. This ensures that all work is
  tracked and visible to the team.
* Agents must create a task for each feature or bug fix they plan to work on. This includes a clear title, description
  of the task, and any relevant links or resources e.g. Allium specifications, design documentation, etc.
* Tasks should be organised into columns based on their status: *Backlog, Ready, In progress, In review, Done* to
  provide a clear visual representation of the project's progress.
